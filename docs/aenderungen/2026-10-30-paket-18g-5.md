# Änderungsnotiz — Paket 18G-5: Studio und Widget

Stand 2026-10-30 · Basis Paket 18G-4 · Plan
[`docs/plans/2026-10-30-paket-18g.md`](../plans/2026-10-30-paket-18g.md)

**Warum:** Das Gesamt-Review fand an den neuen Oberflächen aus Paket 18C/D kleine Fehler: falsche
Seitennamen, eine Suche, die an einer kopierten Fehlerblase scheiterte, einen Knopf, der den Fokus
verlor, und eine Sprungmarke, die still nichts tat.

| Was | Wie |
|---|---|
| Seitenname | Das Debug-Feld des Widgets und die Plugin-Doku nennen die Studio-Seite „Sessions“ (bisher „Gespräche“) |
| Suche nach Fehlernummer | Die ganze Blase oder die Zeile „(Fehlernummer: …)“ lässt sich einfügen, auch ohne Doppelpunkt und mit Satzzeichen am Ende; der Knopf bleibt beim Suchen fokussierbar (`aria-disabled`, WCAG 2.4.3); Treffer aus mehreren Sitzungen sagen, dass die Nummer nicht eindeutig ist |
| Verlauf | Liegt die gesuchte Nachricht hinter den 200 neuesten, sagt der Verlauf es (erst nach dem Laden, als Live-Region) |
| Zugakte | Die Kopfzeile zählt auch ausgelassene Aufrufe; „Abgebrochen (Frist)“ und „Unerwarteter Fehler“ übersetzt, abgebrochene Aufrufe nicht rot (oft ein verworfener Vorabruf) |
| Typen | `debug` der Chat-Probe kann `null` sein; die Agent-Probe behandelt das |
| Widget-Konsole | Fehler erscheinen nur mit ihrer Art (`fehlerKurz`) — Sammlungs-Aktionen, Sprache, Strom, Attribute, vorbereitete Änderung |
| Tests | E2E-Kontrastprobe für das Debug-Feld ohne Freigabe; Gleichlauf der Länge der Fehlernummer zwischen Backend und Studio |

## Was sich im Betrieb ändert

| Was | Muss | Kann |
|---|---|---|
| Image | neu bauen (Widget und Studio); keine Migration | |
| Browser-Plugin | Bündel neu holen (Widget-Texte) | |

## Prüfung

- Widget-Bibliothek: volle Suite. E2E: `contrast.spec.ts`.
