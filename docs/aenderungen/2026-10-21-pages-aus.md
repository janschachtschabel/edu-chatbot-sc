# Änderungsnotiz — GitHub Pages aus, Verweise auf die PNGs

Stand 2026-10-21 · Basis `main` `1b963e6` · nur Dokumentation.

**Warum:** Das Repository ist seit dem 21.10. privat. Auf GitHub Free gibt es für private
Repositories kein Pages; GitHub hat die Seite abgeschaltet, der Lauf `pages` nach dem Merge von #24
scheiterte („Get Pages site failed“). Die Repo-Variable `PAGES_AKTIV` steht jetzt auf `false`, der
Workflow wird damit übersprungen statt rot.

| Was | Wo |
|---|---|
| Links auf die Pages-Adresse ersetzt: PNGs (zeigt GitHub direkt an), interaktiv lokal über `index.html` | `README.md`, `docs/architektur.md`, `docs/uebergabe-betrieb.md`, `docs/steckbrief-uebergabe.md`, `docs/architektur-grafiken/README.md` |
| Abschnitt „Veröffentlichen mit GitHub Pages“ als „derzeit aus“, mit Weg zurück | `docs/architektur-grafiken/README.md` |

Wieder einschalten: Repository öffentlich oder bezahlter Plan, Pages-Quelle „GitHub Actions“,
`PAGES_AKTIV=true`, dann *Actions → pages → Run workflow*.
