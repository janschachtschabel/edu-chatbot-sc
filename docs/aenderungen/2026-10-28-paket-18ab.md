**Warum:** Ein externes Störtest-Audit fand, dass ein Moderationsausfall still bleibt und dass Fragen
nach zwei Medientypen („Arbeitsblatt oder interaktives Material“) nur einen Typ liefern. Die übrigen
Punkte (Inhalte in Logs, Fehlertexte, Exceptions, Betrieb) folgen in 18C–18F. Die Befunde eines
unabhängigen Reviews sind in die Commits eingearbeitet.

| # | Commit | Was |
|---|---|---|
| 1 | Moderationsausfall ehrlich verbuchen | `stages_failed` + Grund `moderation_unavailable`, keine Herabstufung ohne Prüfung (auch bei ausgefallener Rechtsprüfung), Zähler `boerdi_safety_stage_total`, Warnung ohne Zugangsdaten, ehrliches Aufwärmen, lange Nachrichten in überlappenden Abschnitten (über ~30 000 Zeichen Anfang und Ende, `moderation_partial`), Regex-Rückfall als ungeprüft, `gather` auf `BaseException` |
| 2 | Schalter (zuerst `MODERATION_BEI_AUSFALL`, siehe 10) | Vorgabe: antworten; sonst Absage; Graph-Knoten `pruefung_fehlt`, Preflight und `/api/agent`; Absagen in der Auswertung; Startwarnungen; Absagetext de/en, Deploy-Doku |

## Was sich im Betrieb ändert

Keine Migration. Ohne neue Einstellungen verhält sich der Dienst wie bisher.

| Was | Muss | Kann |
|---|---|---|
| Image | neu bauen und ausrollen (nur Backend; das Widget-Bundle ist unverändert) | |
| `MODERATION_FAILURE_MODE` (neu) | | Betriebsentscheid: `open` (Vorgabe) antwortet auch ohne Moderation und meldet den Ausfall; `closed` antwortet dann mit einer Absage. Für Schulbetrieb `closed` erwägen — nur mit erreichbarem Moderationszugang (nicht `b-api-academiccloud`, sonst wird jeder Zug abgewiesen; der Start warnt) |
| `RAG_UMWANDLUNG_FRIST_S`, `RAG_UMWANDLUNG_MAX_MB` | in der `.env` bzw. den Helm-Werten auf `RAG_CONVERSION_TIMEOUT_S`, `RAG_CONVERSION_MAX_MB` umbenennen, **falls gesetzt** | bis dahin wirken die alten Namen weiter (Startwarnung „ist veraltet“) |
| Monitoring | | Zähler `boerdi_safety_stage_total{stage,outcome}` und Alarmregel `BoerdiModerationFaellt` (Beispiel in `deploy/helm/values.example.yaml`) übernehmen |
| Krisensperre im Seed | | folgt beim `migrate` dem Werk. Ist im Studio eine eigene Fassung von `01-base/safety-config` aktiv, dort `search_wlo_all` bei den gesperrten Werkzeugen ergänzen |
| Logs | | neue Warnungen: „moderation not configured …“ (einmal je Prozess), „moderation skipped …“, die Startwarnungen oben |

**Abweichung vom Plan (Bestätigung offen):** Bei mehreren Typen ersetzt der Typ-Fokus die Antwort
weiter durch den Suchhinweis (wie bei einem Typ), statt ihn anzuhängen. Begründung im Plan, 18B.
