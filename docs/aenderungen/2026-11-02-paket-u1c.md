# Änderungsnotiz — Paket U1-c: Treffer und Links als UI-Module

Stand 2026-11-02 · Basis: U1-b (`docs/aenderungen/2026-11-02-paket-u1b.md`) · Plan
[`docs/plans/2026-11-02-paket-u1-ui-module.md`](../plans/2026-11-02-paket-u1-ui-module.md) §12

**Warum:** Nach der Dokument-Box werden die Trefferboxen und die Webseiten-Box zu UI-Modulen.
Entscheide des Nutzers vom 2026-11-02:
- Blöcke kommen **zusätzlich**; `cards`/`web_links` bleiben.
- **Linkbox zuerst**, dann die Trefferliste.
- Im Agent-Modus entstehen die Blöcke **automatisch** aus den Treffern.

| Teil | Was |
|---|---|
| U1-c1 Linkbox | Modul `ui_linkbox`, aus `web_links` abgeleitet (live und Verlauf, gleiche Kennung, Grenze `webseiten_max`); mit Block schweigt die bisherige Box. Zwei Plätze für Module (`oben`/`unten`), Host-Funktion `link()` |
| U1-c2a Trefferliste | Modul `ui_trefferliste` aus `cards`/`query_metas`/`pagination` abgeleitet; zeigt im Textlink-Modus die bisherigen Boxen samt Such-Absprung und „Inhalt anzeigen“ (Adapter) |
| U1-c2b Kacheln | Dasselbe Modul zeigt im Kachel-Modus die Kachelliste (Adapter auf `card-list`) mit Sammlung öffnen, Lernpfad, „Inhalt anzeigen“, „mehr anzeigen“ (Zustand im Modul) und „mehr laden“ (Host lädt, schreibt die Karten in den Block); mit Block schweigt die bisherige Kachelliste, Web-Links stehen nach den Treffern |
| Muster | Neuer Frontmatter-Schlüssel `ui_module` (fehlt = alle abgeleiteten Module, `[]` = keines), im Studio unter „Tools & Wissen“ |

## Was sich im Betrieb ändert

| Was | Muss | Kann |
|---|---|---|
| Image | Backend und Studio neu bauen, mit neuem Widget-Bündel; keine Migration, keine neue Umgebungsvariable | |
| Widget | Eingebettete Kopien neu ausliefern (auch die Kopie im Chrome-Plugin) — ein Widget aus U1-a bis U1-c1 kennt `ui_trefferliste` bzw. `ui_linkbox` nicht und zeigt Treffer und Links doppelt (Textfassung oben und alte Boxen) | |
| API | | `ui.ui_bloecke` trägt zusätzlich `ui_trefferliste` und `ui_linkbox`; `cards`, `query_metas`, `web_links` unverändert |
| Muster | | `ui_module:` wählt die abgeleiteten Module des Musters: fehlt = alle (`ui_trefferliste`, `ui_linkbox`), `[]` = keines (dann die bisherigen Boxen), `[ui_trefferliste]` = Treffer als Modul, Web-Links in der bisherigen Box |
| Aussehen | | Im Textlink-Modus stehen die Webseiten jetzt nach dem Such-Absprung |
