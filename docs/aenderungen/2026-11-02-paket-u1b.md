# Änderungsnotiz — Paket U1-b: Inhaltsrahmen als erstes UI-Modul

Stand 2026-11-02 · Basis: U1-a (`docs/aenderungen/2026-11-02-paket-u1a.md`) · Plan
[`docs/plans/2026-11-02-paket-u1-ui-module.md`](../plans/2026-11-02-paket-u1-ui-module.md) §11

**Warum:** Die Dokument-Box (Lernpfad, Material, Verlaufsplan, Volltext, Schreib-Vorschau) ist
die erste Fläche, die zum UI-Modul wird. Entscheide des Nutzers vom 2026-11-02: Dokumente reisen
gleich als `ui_bloecke`, und das Werkzeug heißt einheitlich `ui_inhaltsrahmen`. Der alte Name
`zeige_dokument` wird weiter angenommen.

| Teil | Was |
|---|---|
| U1-b1 Modul | `ui_inhaltsrahmen` in `frontend/projects/ui-module`: gleiches Aussehen wie die Box, Drucken (auch als PDF) und neu Download als Markdown; Host mit `drucken()`/`markdown()`; Schriftgröße aus den Anzeige-Regeln; keine doppelte Druckleiste |
| U1-b2 Backend | Werkzeug aus dem Manifest, Prüfung beim Aufruf (Fehler mit Feldern an die KI), Alias `zeige_dokument`; jede Box (Werkzeug, geratene Box, Volltext, Schreib-Vorschau, Lernpfad-Direktaktion) als Inhaltsrahmen-Block, Dokumente vor den übrigen Blöcken |
| Leser | Golden-Lauf, Eval-Runner, Studio-Probe, Widget-Wiederherstellung |
| U1-b3 Aufräumen | Alte Box `boerdi-inline-documents` samt Durchreichung, Druck-Auslöser, Rückfall auf `ui.dokumente` und Texten aus dem Widget entfernt (U-F5: das Modul trägt alle Funktionen) |
| Texte | Rollen-Vorgabe, Master-Skill-Vorlagen (`docs/skills/`), Studio-Referenztexte, Doku |
| Vertrag | `inline_documents` (immer leer) und `ui.dokumente` in OpenAPI als veraltet markiert; die Felder bleiben |

## Was sich im Betrieb ändert

| Was | Muss | Kann |
|---|---|---|
| Image | Backend und Studio neu bauen, **mit neuem Widget-Bündel**; keine Migration, keine neue Umgebungsvariable | |
| Widget | Eingebettete Kopien neu ausliefern (auch `examples/chrome-plugin/vendor/boerdi-widget.js`) — ein Widget von vor U1 zeigt keine Dokument-Box mehr | |
| Master-Skill live | | Die in WLO abgelegte Fassung auf `ui_inhaltsrahmen` umstellen (bis dahin greift der Alias) |
| Rollen-Vorgabe | | Eine im Studio gespeicherte eigene Rollen-Vorgabe auf `ui_inhaltsrahmen` umstellen (Alias greift) |
| API-Nutzer | Wer `inline_documents` liest, liest künftig `ui.ui_bloecke` (Modul `ui_inhaltsrahmen`, `daten.titel/art/markdown`) | |

## Reviews

Durchsetzung der Fähigkeiten im Host (nach U1-d verschoben). U1-b2: ein hoher (Alias in der

## Offen

Bei `display_rules.inline_documents.enabled=false` hängt `turn_persist` den Inhalt erst nach dem
Speichern an den Text — nach dem Neuladen und im Folgezug fehlt er (schon vor U1-b so).
