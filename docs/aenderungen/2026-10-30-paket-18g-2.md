# Änderungsnotiz — Paket 18G-2: Log-Lecks

Stand 2026-10-30 · Basis Paket 18G-1 · Plan
[`docs/plans/2026-10-30-paket-18g.md`](../plans/2026-10-30-paket-18g.md)

**Warum:** Das Gesamt-Review fand Stellen, an denen Texte fremder Dienste trotz der Schwärzung aus
Paket 18E ins Log kamen — immer dort, wo der Text schon vor dem Loggen fertig formatiert war. Der
größte Fall: ein MCP-Fehler `-32603` stand mit dem Text des Servers bis zu viermal auf ERROR.

| Was | Wie |
|---|---|
| Fertig formatierte Gründe | `obs/log_format.ausnahme_text` gibt den Grund einer Ausnahme logtauglich: Gruppen aufgelöst, Fremdfehler nur mit Art, HTTP-Status und JSON-RPC-Code. MCP-Transport, MCP-Client und die Fehlerzeile des Stroms nutzen ihn |
| Fremdfehler | Auch eine Hülle, die den Text eines Fremdfehlers übernimmt, gilt als fremd; instructor steht in der Liste; Status und Code bleiben in Meldung und Traceback stehen |
| Datenbank | Ein unpassender asyncpg-Parameter erscheint ohne seinen Wert |
| Einzelstellen | Vokabelabgleich nur mit der Länge der Modellantwort; Kontext-Begrüßung ohne Kennung der Seite |
| MCP-SDK | Logger „client“ gedeckelt; Zeilen, die das SDK über die Wurzel schreibt, ohne `LOG_CONTENT` nur mit Satzanfang und Ort |
| Tracing (G-E3) | Server-Spans ohne IP, Port, User-Agent und Abfrage-Teil; Ausnahmen (FastAPI, SQLAlchemy) nur mit ihrer Art — Text und Traceback gehen nicht an den Collector |
| Wächter | Der Test gegen Inhalte im Log erkennt vorformatierte Texte, `if not … log_content`, camelCase, Logger-Ketten, `fatal`; Fehltexte von Servern mit Begründung (`log-ok`) |
| Kanarienvogel | Neue Fälle (MCP `-32603`, Strom-Fehlerzeile), die instructor-Attrappe wirft wie im Betrieb, der Fänger schwärzt wie der Betrieb |
| Doku | `LOG_CONTENT` öffnet die Fremd-Logger auch unter INFO; Fremd-Logger-Stufen (instructor CRITICAL); Tracing |

## Was sich im Betrieb ändert

| Was | Muss | Kann |
|---|---|---|
| Image | neu bauen; keine Migration | |
| Tracing | | Mit `OTEL_EXPORTER_OTLP_ENDPOINT` fehlen in Spans jetzt IP, User-Agent, Abfrage und Ausnahmetexte |
| Log | | MCP-Fehlerzeilen nennen `McpError(code=…, ‹geschwärzt›)`; geschwärzte Fremdfehler tragen `status=`/`code=` |
